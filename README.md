## Eventify 🎉

**Eventify** is a modern and responsive event-planning website designed to make organizing and managing events easier. It provides users with a simple platform to explore events, plan gatherings, and manage event-related information in one place.

## 📌 Project Description

Eventify is a web development project created as part of our final course project. The website focuses on providing a user-friendly and professional experience for people who want to plan and organize different types of events.

The project is designed to be responsive, so it can be accessed on desktops, tablets, and mobile devices.

## ✨ Features

* 🏠 Modern and responsive homepage
* 📅 Event planning and management
* 🎉 Different event categories
* 📝 Event registration/details
* 👤 User-friendly interface
* 📱 Responsive design for different screen sizes
* 🔍 Easy navigation
* 💻 Clean and organized website structure

## 🛠️ Technologies Used

* **HTML** – Website structure
* **CSS** – Styling and responsive design
* **JavaScript** – Interactive functionality
